02 / THE THINKING

Why these tools?

Start with Phoenix’s existing conventions.

Phoenix already provides routing, generators, LiveView integration, authentication scaffolding and a test setup. We recommend using those before building an alternative structure.

Phoenix overview

Use contexts and Ecto for the first application.

Our default keeps business operations in plain Elixir modules and database access explicit. Ash is worth evaluating early if its resource model, policies and generated APIs fit the product. It is a substantial architectural choice.

Ash’s approach to application design

Make the operational requirements visible.

Oban uses the application database for persistent jobs. Swoosh still needs an email provider. LiveView uploads still need durable storage. A library recommendation should explain the remaining setup.

What people use

In the State of Elixir 2025 survey, Phoenix was used by 97.1% and LiveView by 85.7% of the 961 respondents to the framework question. The survey is self-selected; these figures support familiarity, not a claim about speed.
